# Launch kit

Release assets for listing version 1.0.0.

- `listing.md` — tagline, descriptions, category, keywords and reviewer scope copy.
- `icon.svg`, `icon-mono.svg` — scalable color and monochrome listing icons.
- `og-image.svg` — 1200×630 social preview source.
- `screenshots/` — 1440×900 listing-ready UI compositions.
- `demo-clip.mp4` — rendered 15-second listing preview.
- `demo-storyboard.md` — 35-second clip shot list and narration.

Export SVG sources to PNG/WebP at marketplace upload time so text remains editable until release.
Regenerate screenshots and the OG asset for every UI-changing version.
