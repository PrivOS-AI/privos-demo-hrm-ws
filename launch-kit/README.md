# Launch kit

Release assets for listing version 2.0.0.

- `listing.md` — tagline, descriptions, category, keywords and reviewer scope copy.
- `icon.svg`, `icon-mono.svg` — scalable color and monochrome listing icon sources.
- `icon.png` — 512×512 RGBA Marketplace icon export.
- `og-image.svg` — 1200×630 social preview source.
- `screenshots/*.svg` — editable 1440×900 listing screenshot sources.
- `screenshots/*.png` — 1440×900 RGB Marketplace screenshot exports.
- `demo-clip.mp4` — rendered 15-second listing preview.
- `demo-storyboard.md` — 35-second clip shot list and narration.

Keep SVG sources editable and upload the matching PNG exports to the Marketplace.
Regenerate the screenshot exports and the OG asset for every UI-changing version.
